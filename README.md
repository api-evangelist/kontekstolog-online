Контекстолог – AI‑сервис для автоматизации и оптимизации рекламных кампаний в Яндекс Директ. Сервис предлагает автоматический подбор минус‑слов, управление ставками, автопилот, интеграцию с Яндекс Метрикой и Telegram, а также генерацию рекламных текстов через нейросеть. Работает внутри аккаунта рекламодателя, не требует передачи данных в сторонние системы, обеспечивает контроль расходов и повышает эффективность рекламных бюджетов.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Контекстолог: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
